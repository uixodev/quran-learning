# Тартиль (Tartil)

PWA для изучения сур и дуа: понять → прочитать → послушать и повторить → запомнить → повторять.
Интерфейс на русском. Работает офлайн, прогресс хранится только на устройстве (IndexedDB).

Сайт: `https://<пользователь>.github.io/quran-learning/` (GitHub Pages, корень репозитория).

## Состояние

| Этап | Что | Статус |
|---|---|---|
| 1 | Каркас PWA, деплой на Pages, скрипты данных (аль-Фатиха + джуз Амма) | ✅ |
| 2 | Список сур, «Понять», «Читать», настройки | ⏳ |
| 3 | Аудио, плеер, «Слушать и повторять», режим фокуса | ⏳ |
| 4 | «Запомнить», повторение (SM-2), прогресс, серия дней | ⏳ |
| 5 | Дуа | ⏳ |
| 6 | Полировка, доступность, тест офлайна, инструкция установки | ⏳ |

## Запуск

```sh
npm ci
npm run dev        # разработка
npm run build      # сборка в dist/ (+ sw.js с предзагрузкой текстов и шрифтов)
npm run preview
```

Деплой: при пуше в `main` workflow `.github/workflows/deploy.yml` собирает сайт и публикует его на Pages.
Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Данные и их источники

Текст Корана, перевод, транслитерация и таджвид **не набирались вручную**: `scripts/build-data.mjs`
скачивает их из источников ниже (версии зафиксированы) и пишет JSON в `data/`.
Полный паспорт сборки — `data/sources.json`.

| Что | Источник (зафиксированная версия) | Лицензия |
|---|---|---|
| Арабский текст (Uthmani), названия сур, тип (мекканская/мединская), число аятов | npm [`quran-json@3.1.2`](https://www.npmjs.com/package/quran-json) (текст — Noble Qur'an Encyclopedia / Tanzil-орфография) | CC BY 4.0 (пакет); текст Корана — условия [Tanzil](https://tanzil.net/docs/text_license) |
| Русский перевод — Эльмир Кулиев | тот же пакет; происхождение — Tanzil `ru.kuliev` | условия Tanzil — **проверьте** [tanzil.net/trans/ru.kuliev](https://tanzil.net/trans/ru.kuliev) перед публикацией |
| Транслитерация (**латиница**) | тот же пакет; Tanzil `en.transliteration` | условия Tanzil |
| Разметка таджвида | npm [`react-native-quran-tajweed@0.1.3`](https://www.npmjs.com/package/react-native-quran-tajweed) (поле `text_uthmani_tajweed` Quran.com), перенесена на базовый текст скриптом выравнивания | MIT (пакет); данные Quran.com |
| Шрифт Amiri Quran 1.003 | [google/fonts](https://github.com/google/fonts/tree/main/ofl/amiriquran) | SIL OFL 1.1 |
| Шрифт Inter 5.2.8 (кириллица/латиница) | npm `@fontsource-variable/inter` | SIL OFL 1.1 |
| Аудио | **не хранится**; скачивается на устройство с [everyayah.com](https://everyayah.com) | — |

### Транслитерация

Кириллической транслитерации с проверенным источником найти не удалось, поэтому используется **латиница**
(Tanzil `en.transliteration`). Поле `tr` в данных и код отображения не привязаны к алфавиту: когда появится
проверенный кириллический источник, достаточно изменить сборку данных (`scripts/build-data.mjs`).

### Краткое введение к суре

Берётся только из данных источника: смысл названия (по-русски), мекканская/мединская, число аятов.
Поле `intro` оставлено пустым (`null`) там, где источника нет.

### Таджвид: как он совмещён с текстом

Разметка Quran.com и базовый текст пишут некоторые знаки по-разному (`ـٰ` против `ىٰ`, `ْ` против `ۡ`,
открытый танвин). `scripts/lib/align.mjs` посимвольно выравнивает два варианта и переносит правила на базовый
текст; сам текст не меняется. На аль-Фатихе и джуз Амма перенесено 2790 из 2794 отметок (99,86 %);
остальные 4 — единичные расхождения в написании «لاً»; они остаются без цвета.

Подписи правил — по описаниям Quran.com. Таджвид показывается как подсказка и не заменяет чтеца или учителя.

### Проверки

```sh
npm run data:verify            # перевод и транслитерация побайтно сверяются с независимой копией Tanzil;
                               # арабский — со вторым источником (QUL) по скелету букв
npm run data:compare-alquran   # ВТОРАЯ проверка с api.alquran.cloud (запускать у себя; из песочницы сайт недоступен)
npm run audio:check            # HEAD-запросы к адресам аудио на everyayah.com (запускать у себя)
```

Результат `data:verify` на момент сборки: 571 аят, перевод ≠ Tanzil: 0, транслитерация ≠ Tanzil: 0,
арабский ≠ QUL по скелету: 1 (80:37 — разное написание «يٕ» / «ئ», орфографический вариант).

### Отображение арабского

Хранимый текст не меняется. При показе (`src/display.js`) три знака «открытого» танвина
U+0657 / U+065E / U+0656 заменяются стандартными U+08F0 / U+08F1 / U+08F2 — так делает и Комплекс царя Фахда;
в Amiri Quran нет U+065E. Начертание то же.

### Добавить все 114 сур

```sh
node scripts/build-data.mjs --all
```

### Аудио (адреса)

`https://everyayah.com/data/{folder}/{сура:3}{аят:3}.mp3`, напр. `…/Alafasy_128kbps/001001.mp3`
(список чтецов — `data/reciters.json`). Папка `Alafasy_128kbps` подтверждена документацией `quran-json`;
`Husary_128kbps` из песочницы проверить не удалось — запустите `npm run audio:check`.
